## Нотолгооны гарал

- `validation.json`: `scripts/verify_and_report.py`-ээр шинээр тооцсон 231 трасс, топологи, бүх кабелийн тасралт, shared-corridor, local access.
- `pytest.txt`: `python -m pytest -q tests --durations=5` бодит гаралт.
- `api-benchmark.json`: Flask test client-ийн хугацаа; `http-benchmark.json`: ажиллаж буй localhost HTTP серверийн хугацаа.
- `notebook.html`, `notebook-figure-1.png`: course kernel-ээр ажиллуулсан notebook-ийн дүрслэл.
- `dashboard-desktop.png`, `dashboard-mobile.png`: ажиллаж буй вебийн browser screenshot.

## Хязгаарлалтыг зөв тайлбарлах

“Сургалтын систем ажиллаж, өгөгдсөн логик шаардлагыг шалгасан” гэдэг нь “Монголын бодит сүлжээнд инженерийн баталгаатай, төсөвлөсөн, физик давхар хамгаалалттай кабель тавих зураг бэлэн” гэсэн үг биш. Уулын өргөн бүс, эх солбицол, ойролцоо ой, голын санал болгосон гарцыг survey/DEM/OSM route/crossing inventory-оор нарийвчлах нь бодит хэрэгжүүлэлтийн дараагийн шат.
