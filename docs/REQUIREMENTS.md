# Шаардлага ба нотолгооны матриц

Эх сурвалж: `Biydaalt_instruction_updated.md`. Эндхүү “гүйцэтгэсэн” нь сургалтын
симуляцийн хүрээнд хамаарна. Бодит барилгын хэмжилт, мөнгөн CAPEX, төхөөрөмжийн
traffic туршилт хийсэн гэж үзэхгүй.

---

## ⚠️ Хийсэн зөрүү: Python хувилбарын шаардлага

**Заавар:** «Back-end: Python 3.9+, Flask».
**Бодит байдал:** `requirements.txt` дахь `networkx==3.7`, `scipy==1.18.1`,
`numpy==2.5.3` бүгд өөрийн метафайлд `Requires-Python: >=3.12` гэж бичсэн.
Иймээс **нэг ч зэрэг нь 3.9 дээр суулж чадахгүй.**

| | |
|---|---|
| **Шалгасан, зөвшөөрөгдсөн** | Python **3.12+** (`pyproject.toml` дээр `requires-python = ">=3.12"`). Энэ ланц нь бүх тест, бүх браузер тест, бүх нотабук дээр ажиллаж байгаа. |
| **Бэлтгэсэн боловч шалгаагүй** | `requirements-py39-candidate.txt`: `scipy==1.11.4`, `numpy==1.26.4`, `networkx==3.2.1`, `shapely==2.0.4`, `pyproj==3.6.1`, `Flask==3.0.3`, `pytest==7.4.4`. Эдгээр нь кодын хэрэглэдэг бүх API-ийг (`scipy.optimize.milp` 1.9+, Shapely 2.0+) өгнө. **Гадаа орчид суулгаж бүх тестийг дахин ажиллуулах хүртэл батлагдаагүй.** |
| **Кодын өөрөө** | `fiberlab/*.py` бүгд Python **3.9 синтаксисээр** байна — `tests/test_environment.py::test_the_source_parses_on_the_oldest_declared_syntax` үүнийг `ast.parse(feature_version=(3, 9))`-аар шалгаж байгаа. |
| **Асуудал** | **Багшийн зөвшөөрөл хэрэгтэй.** 3.9 lane-ийг бүрэн шалгахын тулд Python 3.9 орчин, хуучин wheel-ууд, сүүлийн бүх тестийн дахин ажиллалт шаардлагатай. |
| **Одоогийн байдал** | 3.12+ lane нь **бүрэн ажиллаж, бүрэн тестэд хамрагдсан**. 3.9 lane нь **зөвхөн боломжит хувилбар**. |

Зааварт «3.9+» гэж бичсэн бөгөөд бид үүнийг **дуухаар биелэх гэж тэмдэглээгүй**.
`docs/RECONSTRUCTION_AUDIT.md` §4 G-03-т энэ нь «биелээгүй зүйл» гэж бүртгэлдсэн.

## Нотолгооны гарал

- `validation.json`: `scripts/verify_and_report.py`-ээр шинээр тооцсон 231 трасс, топологи, бүх кабелийн тасралт, shared-corridor, local access.
- `pytest.txt`: `python -m pytest -q tests --durations=5` бодит гаралт.
- `api-benchmark.json`, `http-benchmark.json`: Flask test client-ийн болон ажиллаж буй localhost HTTP серверийн хугацаа.
- `notebook.html`, `notebook-figure-1.png`: course kernel-ээр ажиллуулсан notebook-ийн дүрслэл.
- `studio-desktop.png`, `studio-mobile.png`: шинэ загварын ажиллаж буй вебийн browser screenshot.
- `browser-qa.json`: ямар браузер, ямар viewport дээр шалгасан, юуг **баталгаажуулсан**, юуг **баталгаажуулж чадаагүй** гэдгийн жагсаалт.

## Хязгаарлалтыг зөв тайлбарлах

“Сургалтын систем ажиллаж, өгдсөн логик шаардлагыг шалгасан” гэдэг нь “Монголын
бодит сүлжээнд инженерийн баталгаатай, төсөвлөсөн, физик давхар хамгаалалттай кабель
тавих зураг бэлэн” гэсэн үг биш. Уулын өргөн бүс, эх солбицол, ойролцоо ой,
голын санал болгосон гарцыг survey/DEM/OSM route/crossing inventory-оор нарийвчлах
нь бодит хэрэгжүүлэлтийн дараагийн шат.

Гурван шинэ загвар — геометр дээрх нийтлэг зурвас, төсөвийн фронт, тасралтын
хугацааны шугам — мөн **модель**. Тэдгээр нь логик баталгааг бүртгэдэг бөгөөд
бодит хэмжилт, зөвшөөрөл, ачаалал, байгалийн эрсдэлийн таамаглал биш гэдгийг
хэсэг бүрдээ тэмдэглэсэн.
