## 5 минутын танилцуулга

Дээд баруун талын **Танилцуулга** товч доорх алхмуудыг автоматаар үзүүлнэ (алхам бүр UI-г тухайн төлөвт оруулна). Гарын товчлуур: `1` `2` `3` топологи солино, `Esc` тасралт/сонголтыг цэвэрлэнэ. Дээд талын сар/нар товч харанхуй горим асаана. Таб, топологи, сонгосон кабель URL-ийн `#`-д хадгалагдах тул хуудсыг дахин ачаалахад төлөв хэвээр үлдэнэ.

1. **Төлөвлөлт** дээр 2-Edge-ийг хараад нийт урт, bridge 0, RTT үзүүлэлтийг тайлбарлана.
2. **MST** сонгоход 21 кабель бүгд bridge болохыг харуулна.
3. Карт дээр кабель дарж эсвэл баруун талын жагсаалтаас сонгоод **Кабель тасалж турших** дарна. MST дээр UB-ээс тусгаарлагдсан хотууд гарна.
4. **2-Edge** рүү шилжээд дахин тасална. Нөөц зам, түүний урт, RTT гарна; бүх хот холбоотой үлдэнэ.
5. **Бүх кабелийн гэмтлийг шалгах** дарж 27/27 гэсэн exhaustive шалгалтыг үзүүлнэ.
6. **Гэмтлийн хамрах хүрээ**-г нэг зурвасын давхцсан кабель болгож, логик нөөц ба физик хам эрсдэлийн ялгааг харуулна.
7. **Хоёр хотын зам** дээр эхлэх/хүрэх хот сонгож хамгийн богино зам бодно. Тасралтын одоогийн төлөв тооцоонд орно.
8. **Өгөгдөл** хэсгээс зангилаа нэмэх/засах/хасах; трассыг боломжит сангаас хасах, сэргээх боломжтой. Төлөвлөлтийн доорх **Сонгосон трассын өртөг засах** хэсгээр өртгийн үржвэрийг солино.
9. **Экспорт**-оос GeoJSON, CSV эсвэл бүтэн JSON авна.
10. **Аргачлал** хэсгээс өгөгдөл, алгоритм, гарцын таамаг ба хэрэглээний хүрээг тайлбарлана.

Засвар `.state/network.json`-д локал хадгалагдана. **Өгөгдөл → Суурь төлөв** командаар анхны 22 хотын хувилбарт буцна. Өөрчлөлтийг хадгалахыг хүсвэл өмнө нь JSON экспорт хийнэ.

## Газрын зураг юу харуулдаг вэ?

- Улаан: MST; цэнхэр: 2-edge; ногоон: full mesh.
- Шар тасархай: Natural Earth-ийн уулын бүс дотор байрлах хотын зайлшгүй local access. Энэ хэсгийг “уул тойрсон” гэж тооцохгүй.
- Ногоон цэнхэр тасархай: бүсүүдийг холбох төлөвлөсөн голын гарц. Бодит гүүрийн баталгаатай байрлал биш.
- Ойртуулахад аймгийн нэр (zoom 5.5+), сумын хил (zoom 7+), сумын нэр (zoom 8+) гарна. **Сум** давхаргын товчоор унтраана. Эх сурвалж GADM 4.1; чиг баримжааны зориулалттай.
- Нуурыг огтолж трасс гаргахгүй. Гарцгүй голын хэсэг болон уулын бүсийг тойрно. Үндсэн трассын хэрчим бүрийг геометрээр шалгасан.

Зай нь бодит замын хэмжилт биш, рельефийн торонд тооцсон маршрут. Өртөг нь weighted-км; төгрөг биш. RTT нь тархалтын тооцоо. Логик 1-edge tolerance нь нийтлэг суваг, төхөөрөмж, байгалийн гамшгийн гэмтлийг бүрэн даах баталгаа биш.

## Давтан баталгаажуулах

Хичээлийн үндсэн хавтсын `.venv-jupyter` орчныг ашиглана:

```bash
cd '/home/sembee/University-coursework/3A_semester/Сүлжээний загварчлал, симуляци/BiyDaalt'
../.venv-jupyter/bin/python -m pytest -q tests
../.venv-jupyter/bin/python scripts/verify_and_report.py
cd frontend
npm ci --no-audit --no-fund
npm run build
```

`BiyDaalt_SSS.ipynb`-ийг Jupyter-д нээгээд **Python (Сүлжээний загварчлал)** kernel, **Restart Kernel and Run All** сонгоно. Өгсөн эх notebook-ийг шинээр өөрчилсөн хувилбараар дарж бичээгүй.

Бүрэн шинэ компьютер дээр `uv`, Node.js/npm шаардлагатай. Launcher Python орчин байхгүй бол `.venv` үүсгэж, `requirements.txt`-ээс суулгана. Хувилбаруудын одоогийн snapshot `requirements.lock.txt`, npm-ийн lock `frontend/package-lock.json`-д бий. Маршрутын cache байхгүй үед сервер эхлэхдээ шинээр бодно; cache-ийн fingerprint нь өгөгдөл болон хөдөлгүүрийн хувилбартай таарч байх ёстой.

## API

`GET /api/network/topologies`, `GET /api/geography`, `GET /api/network/audit`, `POST /api/network/simulate-cut`, `POST /api/network/path`, `POST/PATCH/DELETE /api/nodes`, `POST/PATCH/DELETE /api/edges/<id>`, `GET /api/jobs/<id>`, `POST /api/network/reset`, `GET /api/export/{geojson,csv,json}`.

Жишээ:

```bash
curl -s http://127.0.0.1:5080/api/network/simulate-cut \
  -H 'Content-Type: application/json' \
  -d '{"topology":"protected","edge_id":"Murun--Uliastai","scope":"cable"}'
```

Топологи/API-ийн warm хариу ба хүйтэн торын preprocessing тусдаа хэмжигдэнэ. Зангилаа засахад HTTP 202 + job ID буцааж, background бодолт дуусмагц шинэ зөв төлөвийг хадгална. Бодолт амжилтгүй бол өмнөх зөв төлөвөө хадгална. Энэ сургалтын локал хувилбар 48 хүртэл зангилааны оролтыг зөвшөөрнө.
