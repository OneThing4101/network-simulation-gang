# Fiber Atlas — Монголын сүлжээний тэсвэрийн студи

22 хотын газарзүйн трасс, Prim MST, Tarjan bridge, MILP нөөц холбоосын оновчлол,
**тооцоолсон тасралтын хугацааны шугам**, геометр дээрх нийтлэг зурвасын шинжилгээ
ба төсөвийн фронт — нэг суурьтай, зургаан сцентай интерактив студи.

**Бүх тооцоо сервер дээр хийгдэж, хариу нь бодит алгоритмын гарал үүсэлт байна.**
Дүрслэл нь үр дүнгээс гардаг; үр дүн байхгүй бол дүрслэл ч байхгүй.

---

## Ажиллуулах

```bash
git clone https://github.com/OneThing4101/fiber-atlas.git
cd fiber-atlas
bash run-fiber-atlas.sh
```

Browser нь **http://127.0.0.1:5080** дээр нээгдэнэ. Launcher шаардлагатай бол
Python орчин (`.venv`) болон frontend build-ийг өөрөө үүсгэнэ. `uv` болон
Node.js/npm шаардлагатай; хоёул шаардлагатай бол `uv` ашиглагдана.

```bash
bash run-fiber-atlas.sh --stop          # серверийг зогсооно
bash run-fiber-atlas.sh --no-browser    # browser-гүй асаана
```

Бэлтгэлтэй машин дээр дахин бүхэлд нь:

```bash
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
cd frontend && npm ci --no-audit --no-fund && npm run build && cd ..
.venv/bin/python -m fiberlab.app
```

## Зургаан сцен

Зүүн талын рейлээс шилжинэ. Топологиг дээд талын хязгаарлалтаас солино
(`1` `2` `3` товч).

| Сцен | Юу харуулна |
|---|---|
| **Атлас** | Карт, сонгосон кабель болон хотын шинжилгээ, топологийн харьцуулалт |
| **Хувьсгал** | Граф хэрхэн байгуулагдсан: боломжит трасс → Prim мод → Tarjan bridge → нөөц цагираг → хамгаалсан сүлжээ. Алхам бүр **тооцоолсон** |
| **Эрсдэл** | Кабель тасах, хугацааны шугам, нөөц зам, гэмтлийн хамрах хүрээ, геометр дээрх нийтлэг зурвас |
| **Зардал** | Төсөвийн фронт: хэр төсөвөөр хэдэн bridge-ийг хамгаалж болно (бүх шат HiGHS-ээр бодогдсон) |
| **Өгөгдөл** | Зангилаа/трассын засах, эх сурвалж, экспорт |
| **Аргачлал** | Алгоритм, таамаглал, хязгаарлалт — тусгал бичиг |

## 5 минутын танилцуулга

1. **Атлас** дээр 2-Edge-ийн үзүүлэлт: 27 кабель, **0 bridge**, 9 088 км,
   хамгийн их RTT 28.3 мс. «Өртөг» мөрөнд 11 239 w-км.
2. `MST` руу шилжэх: 21 кабель, **21 bridge**, 5 889 км. Модны холбоос бүр
   ганц замтай — нэг кабель тасахад хот сална.
3. **Эрсдэл** сценд очиж, нэг кабель сонгон **«Кабель тасалж турших»** дарна.
   Хугацааны шугам: *Эхний төлөв → Гэмтэл илэрсэн → Шинэ төлөв*. MST дээр
   **21 хот салсан** гэж гарна.
4. `2-Edge` рүү шилжээд **яг адил кабелийг** тасана. Одоо дөрөв дэх хүрээ
   гарна: *Нөөц зам* — 773 км, RTT 7.7 мс, **бүх хот холбоотой**.
5. **Эрсдэл** сценын «Логик хамгаалалтын географийн дүнцэг» блокийг залгана.
   Энэ нь проектын гол олдвор: **23 хослоос 14 нэмэлт холбоос** хамгаалж
   байгаа модны холбоосоо 1 км-ээс дээш уртаар **зэрэгцээ явж** байна; хамгийн
   их нь **247.6 км**. Өөрөөр хэлбэл логик 2-edge баталгаа нэг шахалд тэсвээргүй.
6. **Зардал** сценд «Төсөвийн хязгаар бодох» дарна: 500 w-км төсөвөөр 3/21,
   2 000-аар 13/21, 4 000-аар **21/21** bridge хамгаалагдана. Задалбарын
   «15–20% нэмэлт» нь энэ өгөгдлөөр **биелэхгүй** — бодит нэмэлт урт +54.3%.

`Esc` цэвэрлэнэ. Сцен, топологи, сонгосон кабель URL-ийн `#`-д хадгалагдаж
тогтмол тул хуудсыг дахин ачаалахад төлөв хэвээр үлдэнэ.

## Карт юу харуулдаг вэ

- **Улаан** MST, **цэнхэр** 2-Edge, **ногоон** full mesh. Эдгээр өнгө зааварт
  тогтоосон бөгөөд сценээр өөрчлөгдөхгүй.
- **Шар тасархай** — уулын бүс доторх хотын заавал local access. «Уул тойрсон»
  гэж тооцохгүй.
- **Ногоон цэнхэр тасархай** — бүсүүдийг холбох *төлөвлөсөн* голын гарц. Бодит
  гүүрийн бүртгэл биш.
- **Улаан тасархай** — тасарсан кабель. **Улбар шар** — олдсон нөөц зам.
- **Улаан өнгөтэй бүргүүлэгдсэн суурь** — нийтлэг зурвасны бүлэг (тийм зориулалттай
  давхаргуудыг асаахад).
- Өргөрөг утас (graticule), хэмжээний шкала, цагны сум, курсорын координат —
  карт нь **хэмжсэн талбай** байхаар бүтээсэн.
- Ойртуулахад аймгийн нэр (zoom 5.5+), сумын хил (7+), сумын нэр (8+).
  Олон хотын нэр давхцахгүйн тул zoom-оос хамаарч багасгаж харагдана.
- Суурь карт: офлайн рельеф (Natural Earth). OSM/CARTO/OpenTopoMap **онлайн**
  tile-ийг ашиглах бөгөөд холбогдохгүй бол офлайн рельефээр үргэлжилнэ.

## Одоо байгаа үр дүн

| | MST | 2-Edge | Full mesh |
|---|---|---|---|
| Кабель | 21 | 27 | 231 |
| Bridge | 21 | **0** | 0 |
| Урт (км) | 5 889.1 | 9 087.7 | 214 426.9 |
| Өртөг (w-км) | 7 284.1 | 11 239.3 | 240 893.1 |
| Нэмэлт урт | — | **+54.3%** | +3 541.1% |
| Хамгийн их RTT (мс) | 38.49 | 28.29 | 21.80 |

Зай нь 5 км алхамтай рельефийн тор дээрх least-cost маршрут — **бодит авто замын
хэмжилт биш**. Өртөг нь харьцуулах **weighted-км** нэгж, төгрөг биш. RTT нь
5 мкс/км тархалтын тооцоо — төхөөрөмж, ачаалал, бодит ping ороогүй.

## Python хувилбар

**Заавар:** Python 3.9+. **Бодит байдал:** `requirements.txt` дахь `networkx==3.7`,
`scipy==1.18.1`, `numpy==2.5.3` бүгд `Requires-Python: >=3.12` тул **3.9 дээр
суулж болохгүй**.

- **Зөвшөөрөгдсөн, бүрэн шалгасан** ланц: **Python 3.12+** (`pyproject.toml`:
  `requires-python = ">=3.12"`).
- `requirements-py39-candidate.txt` нь 3.9-ийн боломжит пинүүдийг жагсаана
  (`scipy==1.11.4`, `numpy==1.26.4`, `networkx==3.2.1`, …) — **гэвч энэ ланцыг
  бүрэн шалгаагүй**, тиймээс багшийн зөвшөөрөл хэрэгтэй.
- Кодын өөрөө Python 3.9 синтаксистэй (`tests/test_environment.py` шалгана).

Дэлгэрэнгүй: `docs/REQUIREMENTS.md` → «Хийсэн зөрүү» хэсэг.

## Юуг баталгаажуулж чадаагүй

- **Firefox/Edge** дээр ажиллааггуй — зөвхөн Chromium.
- **Онлайн OSM/CARTO tile** дүрслэгдээгүй (окручийн сүлжээний хязгаар).
- **Бодит авто/төмөр замын трасс** оруулаагүй (зааварт optional; OSM-ийн лиценз,
  зөвшөөрөл, routing pipeline дутуу).
- **Бодит ачаалал, хүчин зүйл, хэмжилт, байгалийн эрсдэл** байхгүй. Одоо
  «зурвасны нийтлэг хамгаалалт» гэж ойлговол **модель**, эрсдлийн таамаглал биш.
- Баталгаа нь **тогтсон нэг MST-ийг** хамгаалах хүрээнд; бүх 2-edge-connected
  сүлжээний глобал оптимум биш.
